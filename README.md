# Cisco Packet Tracer - Two PC Ping

## 📌 Project Overview

This is my first Cisco Packet Tracer networking project.

In this project, I connected two PCs directly using an Ethernet cable and configured static IP addresses to test communication using the `ping` command.

## 🖥️ Network Topology

```text
PC0 ─────────────── PC1
```

## 🔧 Configuration

### PC0

* IP Address: `192.168.1.1`
* Subnet Mask: `255.255.255.0`

### PC1

* IP Address: `192.168.1.2`
* Subnet Mask: `255.255.255.0`

## 🧪 Testing

From PC0, I used:

```text
ping 192.168.1.2
```

The ping was successful, confirming that both PCs can communicate with each other.
